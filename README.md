# 🌿 MRITYUNJAY AYURVEDA
### Ancient Wisdom. Natural Wellness.

A premium, modern and responsive Ayurvedic wellness e-commerce website built using **HTML5, CSS3 and Vanilla JavaScript**.

MRITYUNJAY AYURVEDA is a frontend showcase project inspired by India's traditional Ayurvedic heritage, botanical ingredients and modern luxury skincare branding.

## 📸 Website Preview

A premium Ayurvedic storefront featuring elegant typography, botanical visuals, forest-green tones, warm ivory backgrounds and subtle gold accents.

## 🚀 Features

- Premium and modern homepage design
- Fully responsive layout
- Product listing and category sections
- Product search functionality
- Category-based product filtering
- Price filtering and sorting
- Individual product detail pages
- Product quick-view modal
- Shopping cart with quantity controls
- Wishlist functionality
- Cart and wishlist saved using LocalStorage
- Checkout preview interface
- Ingredient information section
- Brand journal and editorial section
- Founder introduction section
- Newsletter subscription UI
- Mobile-friendly navigation
- Smooth animations and hover effects

## 💻 Run Locally

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder:

```bash
cd MRITYUNJAY-AYURVEDA
```

3. Open the folder in VS Code.

4. Run `index.html` using the Live Server extension.

No npm installation or build process is required.

## ⚠️ Project Disclaimer

This website is developed for portfolio and demonstration purposes.

- Product names and prices are sample content.
- Product imagery is concept branding artwork.
- No real payments or orders are processed.

- Product formulations, ingredients, certifications and regulatory details require verification before commercial use.
